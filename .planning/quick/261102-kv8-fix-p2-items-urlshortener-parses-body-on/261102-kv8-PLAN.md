<objective>
Close three P2 reliability/security items from the 2026-11-02 review.

1. `urlShortener.shortenURL` calls `response.json()` before looking at the status. A 429 or 502 served by a gateway with an HTML body throws a SyntaxError, which the generic catch turns into an "unknown" error: the UI loses the `rate_limited` type and the `Retry-After` value. The same catch maps every `TypeError` to "Network error", hiding real bugs.
2. `latencyStorage`'s save/delete/getAll paths `JSON.parse` the whole store without validation (`loadLatencyConfig` validates only the one entry it returns). A corrupt store (e.g. `42` or `[]`) makes `saveLatencyConfig` throw inside its try/catch on every call, so calibration can never be saved again until the key is cleared by hand. `getAllLatencyConfigs` returns whatever was stored, typed as valid configs.
3. `ShareModal.handleSocialShare` opens third-party windows with a feature string but no `noopener`, so the opened page receives `window.opener` (reverse tabnabbing).

Review corrections recorded here: `midiStorage.loadMIDIConfig` already validates with `MIDIConfigSchema` (nothing to do), and `handleSocialShare` is synchronous, so the earlier "popup blocked after an await" claim was wrong; the real fix on that line is `noopener`.
</objective>
